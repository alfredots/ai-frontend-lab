# Conversor de extrato / fatura

Ferramenta estática (HTML + JS) que converte texto copiado de extrato bancário ou fatura de cartão em um arquivo `.txt` padronizado com colunas: data, estabelecimento, tipo de transação e valor.

## Uso local

Abra `index.html` no navegador ou sirva a pasta com qualquer servidor estático.

## GitHub Pages

Após push na branch `main`, o projeto é publicado automaticamente em:

`https://<seu-user>.github.io/ai-frontend-lab/conversor-extrato/`
