# Comparador de Preço por Unidade

Ferramenta offline (HTML + CSS + JS puro) para comparar o custo-benefício de produtos calculando o preço por unidade base (litro, kg ou unidade).

## Funcionalidades

- Adicionar/remover produtos com nome, preço, quantidade e unidade (L, mL, kg, g, un)
- Conversão automática para a unidade base (ex: mL → L, g → kg)
- Destaque visual do produto com melhor custo-benefício e diferença percentual
- Campo "quanto você precisa" para calcular embalagens necessárias e custo total
- Persistência em `localStorage`, com botão para limpar

## Uso

Basta abrir o `index.html` no navegador, não há dependências nem build.
